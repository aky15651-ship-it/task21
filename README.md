# Food Delivery Landing Page

## Project Overview

This project is a responsive single-page food delivery landing website created using HTML and CSS.

The main purpose of this project is to practice:
- HTML structure
- CSS layouts
- Responsive design
- Section alignment
- Image handling
- Modern UI styling

The website is inspired by a food delivery brand landing page design.

---

## Features

- Responsive navigation bar
- Hero section with background image and dark overlay
- Call-to-action buttons
- How It Works section
- Mobile app download buttons
- City cards section
- Customer testimonials section
- Pricing plans
- Footer section with links and social icons

---

## Technologies Used

- HTML5
- CSS3

## How To Run

1. Download or clone this project.

2. Open the project folder.

3. Open `index.html` file in any browser.

OR

4. Open the project in VS Code and use Live Server extension.

The website will run directly in the browser.

---

## Responsive Breakpoints Used

### Desktop

- Screen size: 1200px and above
- Full grid layout
- Horizontal sections

### Tablet

- Screen size: 600px to 900px
- Sections adjust automatically
- Cards change into 2 column layout

### Mobile

- Screen size: Below 600px
- Single column layout
- Navigation and content stack vertically
- Images resize properly

---

## Design Highlights

- Dark overlay on hero and testimonial images for better readability
- Flexible grid system using CSS Grid
- Responsive layout using CSS Media Queries
- Clean spacing and consistent styling
